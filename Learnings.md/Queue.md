Queue in Java

A Queue follows FIFO -- First In, First Out, like people standing in
a line.

- Enqueue: insert at the rear.
- Dequeue: remove from the front.
- Peek: view the front value without removing it.
- Overflow: trying to insert into a full fixed-size queue.
- Underflow: trying to remove from an empty queue.


Complexity
  Operation     Time
  Enqueue       O(1)
  Dequeue       O(1)
  Peek          O(1)
  Display       O(n)
