Stack in Java

A Stack follows LIFO -- Last In, First Out. The last value inserted
is the first one removed, like a pile of plates.

Main operations

- Push: add an element at the top.
- Pop: remove and return the top element.
- Peek: view the top element without removing it.
- isEmpty: check whether the stack is empty.
- Overflow: push into a full fixed-size stack.
- Underflow: pop from an empty stack.


Complexity
  Operation     Time
  Push          O(1)
  Pop           O(1)
  Peek          O(1)
  Display       O(n)
